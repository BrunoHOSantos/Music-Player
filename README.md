# 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **Music Player Web**, inspirado em plataformas modernas de streaming de música.

A aplicação permite ao usuário interagir com uma interface de reprodução musical, utilizando recursos desenvolvidos principalmente com **JavaScript**, sem depender de um framework para controlar a lógica principal do player, com isso, ele possa ter um "Professor IA", em que foi amplamente treinado para responder todas as duvidas possíveis sobre o projeto ou qualquer outra duvida sobre as linguagens.

O projeto foi desenvolvido como parte de um **Bootcamp**, tendo como objetivo cumprir o desafio do projeto, para que se possa demonstrar oque e possível fazer hoje em dia com IA.

Além de funcionar como um player de música, o projeto também serve como laboratório para estudar conceitos importantes do desenvolvimento Web, como:

* Manipulação do DOM;
* Eventos do JavaScript;
* Funções;
* Arrays e objetos;
* Estruturas condicionais;
* Estruturas de repetição;
* Manipulação de elementos HTML;
* Controle de áudio através da Web Audio/HTMLMedia APIs;
* Atualização dinâmica da interface;
* Organização de código;
* Separação de responsabilidades;
* Responsividade;
* Experiência do usuário (UX);
* Acessibilidade;
* Organização de projetos no GitHub;
* Documentação utilizando Markdown;
* Utilização de Inteligência Artificial como ferramenta de apoio ao desenvolvimento.

└──────────┬──────────┘
           │
           ▼

O HTML fornece a estrutura.

O JavaScript funciona como o "cérebro" da aplicação, controlando os eventos e o comportamento do player.

# 🎼 Sistema de Playlist

As músicas podem ser armazenadas em uma estrutura de dados utilizando JavaScript.

### Exemplo:

```javascript
const songs = [
    {
        title: "Nome da Música",
        artist: "Nome do Artista",
        album: "Nome do Álbum",
        cover: "./assets/images/album.jpg",
        audio: "./assets/audio/music.mp3"
    },

    {
        title: "Outra Música",
        artist: "Outro Artista",
        album: "Outro Álbum",
        cover: "./assets/images/album-02.jpg",
        audio: "./assets/audio/music-02.mp3"
    }

```

Essa estrutura permite que o JavaScript trabalhe com várias músicas de maneira organizada.

# ▶️ Reprodução de Áudio

O navegador disponibiliza recursos próprios para trabalhar com áudio.

Um exemplo básico:

```javascript
const audio = new Audio("./assets/audio/music.mp3");

audio.play();
```

Para pausar:

```javascript
audio.pause();
```

Para verificar se o áudio está sendo reproduzido:

```javascript
if (!audio.paused) {
    console.log("A música está tocando");
}
```

---

# 📊 Barra de Progresso

A barra de progresso permite que o usuário visualize a posição atual da música.

Um conceito importante é:

```javascript
audio.currentTime
```

que representa o tempo atual da reprodução.

Já:

```javascript
audio.duration
```

representa a duração total da música.

Essas propriedades podem ser utilizadas para calcular a porcentagem da barra:

```javascript
const progress =
    (audio.currentTime / audio.duration) * 100;
```

---

# 🖱️ Eventos

Grande parte da interação do projeto acontece através de eventos.

Por exemplo:

```javascript
playButton.addEventListener("click", () => {
    audio.play();
});
```

Nesse caso:

1. O usuário clica no botão;
2. O evento `click` é detectado;
3. O JavaScript executa a função;
4. A música começa a tocar.

# 🧩 Exemplo de Manipulação do DOM

Um elemento HTML:

```html
<h2 id="song-title">
    Nome da música
</h2>
```

Pode ser acessado através do JavaScript:

```javascript
const songTitle =
    document.querySelector("#song-title");
```

E seu conteúdo pode ser alterado:

```javascript
songTitle.textContent =
    "Nova Música";
```

Isso permite que a interface seja atualizada automaticamente conforme a música muda.
